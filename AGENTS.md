AI Conversation Logging

Save AI conversations in the ai-logs/ folder at the repository root.

-   Save user prompts and AI responses in Markdown files.
-   Create a separate file for each conversation session.
-   Use the naming format: YYYY-MM-DD-session-NN.md.
-   Preserve actual conversation messages; do not replace them with
    summaries.
-   Update ai-logs/README.md with links to saved conversations.
-   Save conversations at the end of each development session.
-   Never overwrite previous conversation logs.
-   Do not include API keys, passwords, tokens, or secrets.
-   Do not fabricate messages or claim to have saved inaccessible
    conversation history.

All conversation logs must remain inside ai-logs/.
